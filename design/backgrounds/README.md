# Background designs (sources)

The couple's three background designs, as supplied (vector EPS). The web
versions in `public/backgrounds/` were made from the JPG previews in the same
archives:

- `vintage-floral.webp` — classic vintage floral texture, resized to 2400 px.
- `decorative-dusk.webp` — abstract background with decorative pattern,
  resized to 2000 px.
- `damask-tile.webp` — the seamless damask cut to exactly one repeat (1360 px
  square at source, found by autocorrelation), scaled to 640 px and shown at
  320 px so it is sharp on 2× screens. Its edges match like any two
  neighbouring columns inside the tile, so it repeats with no seam.

Check the licence that came with each design before publishing.
