# Monogram faces

Twenty typefaces the couple can set their monogram in from the dashboard —
ten Latin, ten Khmer. Every one is licensed **SIL Open Font License 1.1**;
the copyright line from each project's own LICENSE follows. The full OFL text
is in `OFL.txt` and applies to all of them.

Only the face actually chosen is ever downloaded by a guest: twenty
`@font-face` rules cost nothing until something on the page is set in one.
